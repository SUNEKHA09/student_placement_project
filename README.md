# 🎓 Student Placement Analysis Dashboard

A Streamlit dashboard to analyze student academic performance, skills, internships, and placement outcomes.

---

## ✨ Features
- Filters: Degree, Placement Status, Domain
- KPIs: Total Students, Placement Rate, Average Package
- Visualizations: Placement distribution, CGPA vs Placement, Internship vs Placement, Skills & Domain analysis
- Salary package distribution and academic performance
- Student dataset table with download option

---
